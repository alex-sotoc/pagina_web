Introducción a la Etiqueta <canvas> y Contextos 2D

La etiqueta HTML <canvas> es un contenedor gráfico introducido en HTML5 que permite renderizar gráficos dinámicos, dibujos 2D y animaciones directamente en el navegador utilizando secuencias de comandos (por lo general JavaScript).

Para poder dibujar en un canvas, es necesario obtener su contexto de renderizado mediante JavaScript utilizando el método canvas.getContext('2d'). Este contexto proporciona propiedades y funciones para trazar líneas, figuras geométricas, rectángulos, círculos, gestionar colores y manipular imágenes píxel a píxel.

Fundamentos de la Librería p5.js

p5.js es una biblioteca de JavaScript basada en los principios de Processing, diseñada específicamente para hacer la programación creativa accesible a artistas, diseñadores, educadores y principiantes.

Simplifica enormemente el trabajo directo con el contexto 2D del canvas nativo mediante una estructura limpia basada en funciones principales:

  • setup(): Se ejecuta una sola vez al iniciar el programa. Ideal para inicializar configuraciones y crear el lienzo con createCanvas().
  • draw(): Se ejecuta de forma continua (o una sola vez si se usa noLoop()), permitiendo renderizar formas primitivas como ellipse(), rect(), triangle() y line() con gran facilidad y control de estilos de color (fill() y stroke()).
